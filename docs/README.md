# Askwerk documentation

| Folder | For whom | Contents |
|---|---|---|
| `docs/user/` | survey authors and administrators | how to build, publish and analyse surveys; settings |
| `docs/operations/` | people running Askwerk | install, upgrade, backup and restore, proxies, observability |
| [`docs/api/`](api/) | integrators | Public API reference (OpenAPI), authentication, webhooks, embed events, SDKs, MCP, versioning policy |
| [`docs/integrations/`](integrations/) | integrators | a plain curl walkthrough, then example integrations |
| `docs/architecture/` | contributors | canonical diagrams, such as the data model |

Rules for contributors and coding agents are not here but in [`agents/`](../agents/AGENTS.md). Folders without a link do not exist yet; they are created with the first document that belongs in them.
