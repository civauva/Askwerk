C26 · SDKs for the Public API: TypeScript, C# and Python · AWK-26 · 2026-10-15

Zero runtime dependencies, generated from docs/api/openapi.json, one hand-written auth helper each (API key, or OAuth client credentials with token refresh), tested against a real Askwerk. Source in src/sdks/ (Apache-2.0).

How they are generated

Recommended: our own small generator (src/sdks/generate.mjs, Node, no package), because every ready-made generator brings runtime packages:

GeneratorLicenceWhat the SDK then needs
openapi-generatorApache-2.0Java to run; Python SDK needs urllib3, pydantic; C# needs Newtonsoft or Polly
Kiota (Microsoft)MITMicrosoft.Kiota.* runtime packages in every SDK
NSwagMITC# and TS only; no Python
openapi-python-clientMIThttpx and attrs in the SDK

The Public API is small (12 operations); a generator of about 400 lines reads the OpenAPI document and writes one typed client per language with the standard library's HTTP client (fetch, HttpClient, urllib). It runs in the build; the snapshot test fails when an SDK is stale.

What a developer writes

// TypeScript (npm: @askwerk/sdk)
import { Askwerk } from "@askwerk/sdk";
const askwerk = new Askwerk({ baseUrl: "https://surveys.acme.at", apiKey: process.env.ASKWERK_KEY });
const { items } = await askwerk.surveys.list({ status: "published" });
const exp = await askwerk.exports.start(items[0].id, { format: "csv" });
const ready = await askwerk.exports.waitUntilReady(exp.id);
// C# (NuGet: Askwerk.Sdk)
var askwerk = new AskwerkClient(new Uri("https://surveys.acme.at"),
    AskwerkAuth.ClientCredentials("cl_…", secret));
var page = await askwerk.Surveys.ListAsync(status: "published");
# Python (PyPI: askwerk)
from askwerk import Askwerk
askwerk = Askwerk("https://surveys.acme.at", api_key=os.environ["ASKWERK_KEY"])
hooks = askwerk.webhooks.list()
  • Errors become one exception type with status, problem type, title and trace id.
  • Cursor paging helpers (iterate all pages); Idempotency-Key on retried creates; 429 waits as Retry-After says.
  • Webhook signature check helper in all three.

Layout, tests, release

src/sdks/
  generate.mjs        reads docs/api/openapi.json
  typescript/         package.json, src/, tests/
  csharp/             Askwerk.Sdk.csproj, tests/
  python/             pyproject.toml, askwerk/, tests/
  • Tests: each SDK runs the same scenario against the API in a container in the full run (list surveys, export, webhook create, OAuth token) — nothing mocked.
  • Version = API version + SDK patch (1.0.x for v1).
  • Release: a manual script builds the three packages into artifacts/; publishing to npm, NuGet and PyPI happens only when you say so, with your accounts.
