One layout language: three page kinds

Canvas · full widthQuestions, Look, Results charts and the survey workspace. The only full-width pages.
List · up to 1,200 pxSurveys, Share, Participants, Members, API keys, Domains, Webhooks, Developers, Administration lists.
Form · up to 720 pxSurvey settings, Account, Security, Organisation and installation settings, Messages.
AllLeft-aligned, 32 px from the sidebar; page title in the bar, never repeated in the page; same 28 px top space; sections as cards with the same padding.

Today the pages use nine widths (640 to 1,280 px), some centred, some not. Three shared layout classes in the UI package replace them, and a browser test measures every page's left edge and width.
