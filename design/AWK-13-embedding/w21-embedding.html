Already built: surveys embed with a script or an iframe on the allowed websites (Organisation → Domains), with started, page, completed and resize events. New: the designer and Results inside a host product, signed in by the host's hand-over token (AWK-12) instead of a cookie, narrowed per survey, and the error states.

Inspector
  • No Askwerk logo, survey list or account menu inside the frame: the host owns the navigation. “Surveys” in the bar sends askwerk:navigate {to: "list"} to the host instead.
  • Events to the host: askwerk:ready, askwerk:saved, askwerk:published {version}, askwerk:resize, askwerk:session-ending.
  • The host's language is passed in (?lang=de or the token's locale) and wins over the browser's.

2How it starts

Host serversigns a hand-over token for the user (AWK-12): issuer, audience, user, role, survey or “designer”, 2 minutes, one-time jti. Host page<iframe src="https://surveys.acme.at/embed/designer?survey=…&token=…"> or the embed script with data-token. Askwerkchecks the token and that the host's origin is allowed, starts an embedded session (a short-lived bearer kept in the frame's memory, refreshed while it is open, 8 hours at most), never a third-party cookie. Frameshows the designer or Results for that survey only; a link elsewhere asks the host via askwerk:navigate.

  • Narrowing per survey: Share tab → Embed → “Only on these sites” (empty = the organisation's list).

Depends on the hand-over token of AWK-12; recommended order: AWK-12 first, then this.
