# Security policy

## Supported versions
Askwerk is in early development and has no release yet. Once it has, the latest minor release of the current major version receives security fixes; this table will list them.

| Version | Supported |
|---|---|
| none released yet | — |

## Reporting a vulnerability
Please **do not** open a public issue. Report privately through one of these:
- GitHub: **Security → Report a vulnerability** on [github.com/civauva/Askwerk](https://github.com/civauva/Askwerk) (private vulnerability reporting).
- Email: **security@askwerk.com**.

Include what you found, how to reproduce it, the version or commit, and the impact you expect. We will:
- confirm receipt within 3 working days;
- give a first assessment within 10 working days;
- agree a disclosure date with you, normally after a fix is released, and credit you unless you prefer otherwise.

There is no bug bounty.

## Scope
In scope: the code in this repository and the official container images. Out of scope: third-party installations we do not operate, and findings that need physical access or a compromised administrator account.
